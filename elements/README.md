# elements · 设计元素库

设计元素 = **与品牌无关、可跨主题复用的装饰 / 图形单元**。比组件更小：组件是"一段版式"，元素是"一个视觉母题"。

> **纪律**：本系统的设计语言只有**三个装饰母题**（胶囊棒 / 签名角 / 色带，见 `../design-language.md`）。
> 元素库不是图库——往里加元素的门槛应当很高。母题越多，越接近"模板堆砌"，与「克制即高级」直接冲突。

## 母题登记表

| 编号 | 母题 | 形态 | 出现页型 | 主题适配 | 状态 |
|---|---|---|---|---|---|
| E01 | 胶囊棒束 | 45° 等距平行圆头长条，按 `d = x − y` 定位 | 封面 / 章节页 / 封底 | 吃 `capsuleDeep` / `functional` / `capsuleLight` | 已实现（`CapsuleDecor`） |
| E02 | 签名角 | 卡片右上角大圆角切角 | 数据卡 / 模板卡 | 吃 `functional` | 已实现（`StatCardRow` scoop） |
| E03 | 递变色带 | 4 档同族递变色带 | 流程时间轴 | 吃 `ramp` | 已实现（`TimelineBar`） |

## 元素规范

- **命名**：`el-<族>-<名称>.svg`；族名从 `motif`（装饰母题）/ `divider`（分隔件）/ `texture`（底纹）/ `marker`（标记）中选
- **必须矢量**：SVG，无位图、无 emoji、不混用描边图标
- **必须可换色**：单色元素用 `currentColor`；多色元素用 CSS 变量承接主题令牌，**不得写死 hex**
- **必须标页型**：注明"允许出现在哪些页型"与"每页最多出现几次"
- **禁止**：渐变球、玻璃拟态、发光描边、装饰性阴影、无意义的圆形/波浪分隔线（见 `../references/anti-patterns.md`）

## 新增元素判定

加之前先自问三句：

1. 现有三个母题 + 已有 16 个图标，真的表达不了吗？
2. 它能在 ≥2 个不同品牌主题下都成立吗？
3. 它会让页面更"有秩序"，还是只是更"花"？

三问有不成立的，就不加。
