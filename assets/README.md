# assets · 品牌素材包

按品牌分目录存放**真实**素材。系统与品牌解耦——品牌的东西全部通过这里注入，不混进组件与模板。

```
assets/
└── <brand-key>/            # 与 themes.js 的 key 一致，如 yuantai/
    ├── brand.md            # 品牌规范：色值（Pantone / hex）、字体、LOGO 用法与安全间距
    ├── logo/               # LOGO 源文件（透明背景 PNG / SVG）
    ├── photo/              # 实景 / 实验室 / 产品图
    └── chart/              # 真实数据图表源文件
```

## 硬规则

1. **禁止杜撰品牌资产**。LOGO、实景图、真实数据必须人工提供。缺素材时用明确的占位块（`〔占位：实验室实景图〕`），不要用 AI 生成的假 LOGO 或编造的图片路径。
2. **AI 生成图仅用于纯装饰**（纹理、抽象背景），且须确认无水印与版权风险；但凡画面里出现"看起来像真实企业 / 真实实验"的内容，一律不用。
3. **公开性红线**（本仓库是 public）：
   - 可以：自有或已授权的品牌素材、已公开发布的数据
   - 不可以：客户保密素材（未公开产品数据、内部实验图、未发布文案）、第三方手册原图
   - 拿不准的项目：素材放本地 `assets-local/`（已在 `.gitignore`，不入库），只在对话与交付物里用
4. **一品牌一目录**，目录名与 `src/lib/themes.js` 的 key 严格一致，便于 Agent 自动对应。
