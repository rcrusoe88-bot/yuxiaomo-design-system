# 出品样例`r`n`r`n> 也可以直接从仓库首页的 [预览入口](../README.md#-预览入口) 打开这些 PDF。

用本系统的同一套组件与文案，仅切换主题，产出的 A4 手册样例：

| 文件 | 主题 | 说明 |
|---|---|---|
| `demo-blue.pdf` | `blue` 深海蓝 | 默认主题；封面 6 根等距平行胶囊棒 |
| `yuantai-demo.pdf` | `yuantai` 远泰红 | 现实项目主题（`#D80000` + 深灰 `#606060`） |

两份 PDF 内容完全一致（5 页：封面 → 端到端服务+流程 → 规格+套餐+等级对比 → 案例+证据 → 封底），**只换了主题令牌**——这正是"一套语言 × 多套主题"的实证。

生成方式：

```bash
node node_modules/vite/bin/vite.js --port 5173   # 另开终端启动预览
node export-pdf.cjs demo-blue.pdf
```

或在浏览器打开 dev server，用顶部主题切换条实时对比各主题。
