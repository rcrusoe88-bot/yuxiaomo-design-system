# templates · 整页参考模板

一个模板 = **可直接套用的一整页 A4 版式**（结构 + 占位文案 + 主题变量），不是组件片段。
用途：拿到新项目时先挑模板拼出骨架，再用真实文案与品牌素材替换，避免每次从空白页开始想版式。

> 组件与模板是两层：**组件是零件，模板是装配好的整页。**
> 模板只放结构，不放任何公司的真实数据与 LOGO。

## 模板规范

- **命名**：`tpl-<场景>-<版式>.html`
- **一份模板一个文件**，独立 HTML，双击即开（样式内联，零外部依赖）
- **A4 尺寸**：`@page { size: A4; margin: 0 }`，每页真实尺寸 `210×297mm`
- **不写死色值**：用 CSS 变量承接主题令牌，换主题只改变量块
- **只放占位文案**：正文写 `〔占位：一句话价值主张〕` 这类标记，不写任何真实公司数据
- **附预览图**：`<模板名>.png`（A4 比例），供索引与快速目检
- **登记**：加进上面索引表，并在 `../references/layouts.md` 对应原型下注一行

## 什么时候才值得新增模板

出现下面任一条，才沉淀成模板：

1. 同一版式在 ≥2 个项目里被重复实现过；
2. 该版式承担明确的叙事功能，且新手容易做错（放进来当"正确示范"）；
3. 现有 7 个原型覆盖不到这个页面句型。
