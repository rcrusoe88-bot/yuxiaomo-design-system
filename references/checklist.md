# 交付前自检清单 · Checklist

> 每一份产品页在交付前，**逐条过一遍**。任何一条不过，先改完再交付。

## A. 色彩与主题

- [ ] 全稿只用**一个色相家族**（R1）——功能性色、表头、浅底、深底都在族内
- [ ] 页面里没有任何写死的十六进制色值，全部走主题令牌
- [ ] 深底只出现在封面 / 章节页 / 封底（R2）
- [ ] 内页主题色实底占比 ≤10%
- [ ] 全稿零阴影、零装饰渐变（R13）

## B. 结构页与标题

- [ ] 封面有 45° **等距平行**胶囊棒（不是随手几根）（R3）
- [ ] 每页**最多一个**实底胶囊标题 `PillTitle`（R4）
- [ ] 小节标题用主题色粗体、居中，与胶囊标题「一"面"一"字"」
- [ ] 页码 `– 0X –` 奇偶左右交替，封面封底无页码

## C. 表格

- [ ] **先判语体（R16）**：营销参数页用 `SpecTable`（实底反白表头）；技术数据页用 `InstrumentReportPanel`（浅底细线表头）。两者不可混在一页
- [ ] 营销参数表：表头**实底 + 白字 + 列间白缝 + 顶角圆**（R5）
- [ ] 技术数据表：表头**浅底深灰字 + 行内加粗**，容器一圈极浅描边
- [ ] 无论哪种语体，表体**一律无竖线**，只有 0.5pt 横线 + 极浅斑马纹
- [ ] 关键数字（周期/产能/效率）已用主题色高亮（R8）
- [ ] 合并单元格、标签列用法正确（无错位）

## D. 卡片与证据

- [ ] 卡片右上角是 scoop 大圆角，**方向全稿一致**（R6）
- [ ] 数字承诺在卡里、参数在表里、证据是原始图（R7）
- [ ] `EvidenceGrid` 里的图是**真实**仪器图；圈选只用绿色虚线框
- [ ] 图表双系列用"浅档 + 深档"同色相；阳性对照才用橙

## E. 流程与叙事

- [ ] 每个流程图下方都跟了 `TimelineBar` 时间轴（R9）
- [ ] **一站一拓扑（R14）**：流程用链、收敛用漏斗、迭代用环、组合用公式——全册没有把同一种图复用在两种语义上
- [ ] 总览页的流程图节点名，与后续每页的小节标题**一一对应**（总-分锚定）
- [ ] `FunnelStages` 里的量化数字**来自真实数据**，非编造
- [ ] 案例是"挑战→解决方案→结果"三段式，末尾有结论横幅（R10）
- [ ] 页面顺序符合叙事铁律（品牌→承诺→卖点→参数→证据→收口）
- [ ] 每个服务单元讲完有留白（R11），无连续两页"密"

## F. 图标与内容

- [ ] 图标全部是面性双色 SVG，风格统一（R12）
- [ ] **图标必入容器（R17）**：无裸放图标，容器色即语义色
- [ ] **量化承诺内联加粗（R18）**：产能/合规/周期数字嵌在叙述里加粗，而非另做统计块
- [ ] **类目色恒定（R21）**：同一类目在全册任何页同色（需要时用 `CategoryTagRow` 的 `color` 显式锁定）
- [ ] 无 emoji、无照片装饰
- [ ] 每个"快/高/稳定"都绑定了具体数字
- [ ] 术语准确（TU 仅指滴度；细胞数用 cells）
- [ ] **无杜撰**：数据/客户/资质/LOGO/实景图均为真实，缺失处明确留占位

## G. 技术核验（A4 印刷）

- [ ] 页面尺寸 = 210×297mm，`@page { size: A4; margin: 0 }`
- [ ] 打印样式含 `print-color-adjust: exact`（否则品牌色变白）
- [ ] 内容无溢出（每页 `overflow: hidden`，超出的已重新排版）
- [ ] 导出 PDF 前已 `await document.fonts.ready`（否则中文变方块）
- [ ] 用 `printBackground: true` + `preferCSSPageSize: true` 导出
- [ ] 逐页截图目检过一遍（`node shot.cjs`）

## H. 反模式终检

对照 `anti-patterns.md` 六类逐项扫一遍：**一色相、三母题、零阴影、满留白、数字说话、素材要真。**

## I. 第二批规则专项（R15 / R19 / R20，来自 MCE）

- [ ] **深浅=顺序，色相=并列（R15）**：表达时间/成熟度递进用同色系深浅；表达并列分类才用异色相——两者没有互换
- [ ] **信任靠同行评议（R19）**：可信度页用 `CitationBlock` 的期刊引用建立，**没有做 logo 墙**
- [ ] **深色收尾（R20）**：封底用深色反转全册浅底，联系方式 + 二维码 + 口号集中在此，视觉重量最重
- [ ] 使用了族 H/I/J 组件时，色相均由 `toneRamp(theme.functional, n)` 派生，**无硬编码 hex**

## J. v0.4 新增专项（标题形态 / 文本 / 拓扑 / 类目色）

- [ ] **标题形态纪律**：H1 一页一个；全册 H1 形态 ≤2 种；全册 H2 只用一种（色条 *或* 细线夹，不混用）
- [ ] **文本高亮只有一种手段**：行内加粗（`**x**`）——无彩色高亮、无底色、无下划线
- [ ] **一语义一拓扑（R14 复核）**：对照 `taxonomy.md` 层 5 的语义表，确认每种关系都用对了拓扑（编号步骤 ≠ 链 ≠ 环 ≠ 网络）
- [ ] **网络图配比**：用了 `ServiceNetworkMap` 时，中枢**独占一整行并跨满列数**（否则"汇聚"语义不成立）；节点箭头只挂右缘/下缘，无悬空箭头
- [ ] **类目色纪律（R22）**：多档配色组件**未传 `palette` 即默认同色相**；凡用了 `palette="category"` 的地方，都能说清"这些颜色各代表哪个类目"，且该类目色全册一致（联动 R21）
- [ ] **小倍数图共享刻度**：用了 `PanelBarChart` 时确认 `sharedScale` 已开（各面板各自缩放会读出错结论）
- [ ] **图不编造**：`LegendFigure` 等图解缺真实插图时，保留"待补插图"占位框，**没有用伪科学图填满**
- [ ] **页眉页脚在页内**：`@page` 无 margin box，`BrandHeaderBar` / `ContactFooterBand` 必须画在 `.page` 内部
- [ ] **溢出已机械校验**：跑过 `npm run verify`，13 页全部"无溢出、零报错"（不能只靠肉眼）
