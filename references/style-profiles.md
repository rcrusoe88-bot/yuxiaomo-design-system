# Style Profiles · 可配置风格层

Style Profile 控制视觉气质，不改变组件语义。品牌 Theme 控制颜色；Profile 控制字体、几何、间距、密度和装饰。

## 初始 Profile

### `neutral-editorial`

适合公司介绍、白皮书、品牌概览。细线、较宽留白、编辑型标题、低装饰。

### `technical-structured`

适合产品参数、服务流程、技术方法和案例证据。明确网格、细线表格、中高信息密度、弱圆角。

### `warm-professional`

适合服务型企业、客户案例和解决方案册。较柔和的几何、适度浅色面板、较强的章节节奏。

## 可配置轴

- `typography`：中文/英文/数字字体、字阶比例、字重。
- `geometry`：圆角、标题形态、线条粗细、卡片形状。
- `spacing`：页面边距、模块间距、表格内距。
- `density`：疏/中/密，以及每页最大结构块数量。
- `decoration`：允许的设计元素母题、图标风格、图像裁切方式。

## 不可被 Profile 改写的规则

- 页面任务和内容语义。
- 表格/图表/流程的适用边界。
- A4 页面尺寸和安全区域。
- 证据优先与事实不可杜撰。
- 组件白名单和组件状态。
- R1、R5、R7、R14、R16、R22、R23 等语义纪律。
